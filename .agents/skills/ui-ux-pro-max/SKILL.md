# UI-UX Pro Max v2.0 Design System Generator

> Multi-domain reasoning engine for high-end landing pages, product UI, and design systems.

## Key Rules & Directives

### 1. Pre-Delivery Checklist
- [x] No emojis as icons (Use Lucide/Phosphor SVGs only)
- [x] `cursor-pointer` on all interactive/clickable elements
- [x] High text contrast >= 4.5:1 against background
- [x] Focus states visible for keyboard navigation
- [x] `prefers-reduced-motion` respected in animations
- [x] Text, chips, and badges reflow without clipping
- [x] Full responsive support: 375px, 768px, 1024px, 1440px

### 2. Styling & Colors (Luxury Barbershop / Lifestyle)
- **Primary Accent:** `#d4af37` (Metallic Gold)
- **Secondary Accent:** `#79b8a7` (Toto Mint)
- **Dark Background:** `#07110f` (Deep Forest Charcoal)
- **Text:** `#f2f5f3` (Soft Light / White)

### 3. Anti-Patterns to Avoid
- Bright neon gradients
- Raw un-styled cards
- Upside-down text on rotating components
- Emoji icons in UI controls
